# readll

**READ ALL** は readll のスローガンです。独自設計の単一ページで書籍と記事を並べ、
画面プレビュー、インストールとダウンロードを提供します。デバイス UI は
[kiikoread](https://kiikoread.com/) を引き継ぎ、基本操作はその
[説明書](https://kiikoread.com/manual/)を参照します。説明書や PDF を複製して配信しません。
readll 固有の RSS と更新仕様は本プロジェクトの説明に従ってください。

下部タブは **首页 / 书架 / RSS / 文件 / 设置** です。RSS タブから Miniflux の未読一覧を 12 件ずつ表示し、タイトル一覧と既読同期の待機操作を保存します。
本文は開く時だけオンライン取得し、一覧へ戻るとメモリから解放します。
本文の永続保存や時間に基づく先読みは行わず、取得失敗時は未読状態を変えません。

プロジェクト、ファームウェア UI、シミュレーター、Web、CMake project、パッケージ名は小文字 **readll** に統一します。`tools/package_flash.py` は USB/WebUSB と TF の資産を生成し、`tools/stage_public_flash.py` は任意の HTTPS 静的ホストへ配置できるサイトを生成します。生成物のサイズ・SHA-256 は `release-assets.json`、任意のローカル公開元マッピングは別 schema の `flash/release-sources.json` を使用します。無効なのは本体内オンライン OTA だけで、新しい readll OTA origin が設定されるまで旧ソースや暗黙のフォールバックを使用しません。

MindReset RDP-G01-W 向けの独立したオープンソース読書ファームウェアです。[MindReset の公式デモ](https://github.com/MindReset/read_pico_firmware)を基にしていますが、**MindReset の公式リリースではありません**。

EPUB と TXT の読書、読書位置の保存、TF カードのファイル管理、Wi-Fi・ホットスポット・USB での転送に対応します。公開サイトは https://ww4yne.github.io/readll/ です。単一ページの生成には `python3 tools/stage_public_flash.py _site --package-dir build/readll-package` を使用します。

オンライン書き込みではブートローダー、パーティションテーブル、アプリ、OTA データ領域を書き込みます。既存の NVS 設定と内部の書籍領域は維持されます。[更新履歴](docs/CHANGELOG.md)も参照してください。

このファームウェアを使用中で自動的にダウンロードモードへ切り替わらない場合は、本体の「设置 → 升级和恢复 → BOOT 刷机 → 进入 BOOT 模式」を選び、PC がシリアルポートを再認識してから書き込みページで再試行してください。

本体内オンライン OTA は未設定です。本体は「在线升级尚未配置」と表示し、更新 URL や旧ソースへのフォールバックを使用しません。WebUSB 書き込みサイト、USB 完全パッケージ、TF パッケージは引き続き利用できます。

TF カード内の任意のフォルダーから TXT/EPUB を開いて読書位置を保存すると、再スキャンせずに書棚へ追加されます。書棚管理の「移出书架」は項目を非表示にするだけで、ファイル・読書位置・お気に入りは残します。再び読むと書棚へ戻ります。非表示の状態は本体に保存し、設定のバックアップと復元にも含めます。

ローカル開発版の「書架拼貼」ロックは、実際の表紙の縦横比・丸角・15°の傾斜を保持し、16階調で描画します。左上のプロフィール名と右下の大きな冊数・小さな単位は、選択したシステム字体の輪郭を直接使用します。淡い表紙には細いグレーの丸角枠を追加します。TFキャッシュと上限付き作業メモリを使い、不足時は安全なロック画面へ戻します。書棚の袋・背表紙形式は廃止し、旧設定はアクリルへ移行します。

「設定 → 個性化機能 → ロックパスワード」は任意の4桁PINで、標準は無効です。有効化は2回一致、変更・無効化は現在のPIN確認が必要です。浅い・深いスリープと冷起動の後、認証してから元の画面へ戻ります。数字の押下を即表示し、有効な指離しで1桁を確定します。取消はロック画像へ戻り、削除は1桁戻します。実際のロック画像は軽いぼかしを一度だけキャッシュします。復帰・冷起動時は完成画面を一度で表示し、丸いロックアイコンと操作部を鮮明に保ちます。入力中に背景を再更新しません。キーの反応は局所白黒更新します。選択したシステム字体を使い、利用不能時は内蔵字体で補完します。保存するのはソルト付きダイジェストだけで、通常の設定バックアップや復元はPINを含めず上書きしません。

自動スリープと手動ロックは選択中の形式を使います。PIN背景のキャッシュは現在の形式・壁紙と一致する場合だけ再利用します。形式や壁紙の変更後は深いスリープからの復帰・冷起動で現在の画像を描き直し、PIN保護は維持します。壁紙形式はプレビューで画像を確定すると選択されます。

EPUB の本文の各章は新しいページから始まり、収まる場合は章題と冒頭の本文を同じページに表示します。一つの XHTML 内の複数の章も対象です。目次リンク、紹介文、著者・著作権情報は本文の章として扱わず、通常の小見出しは続けて表示します。章の検出には目次、番号付きの独立した章題と本文構造を使うため、適切なマークアップのない書籍は個別の互換性対応が必要になる場合があります。

余白のスライダーは現在の字体サイズと字間隔で実際の表示幅が異なる段階だけを示し、反応がないように見える重複を除きます。設定画面の再描画では保存済み余白を変更しません。

フォント設定は読書字体と字重、書内字体のスイッチと組版をそれぞれ左右に配置し、読書背景の入口を削除しました。設定は「接続と時刻」「表示」「個性化機能」「更新と復元」に整理し、時刻はBluetoothの次、ホーム更新方式はシステムコントラストの次に置きます。自動ロックと電源オフ睡眠は表示、書棚形式・ロック形式・PIN・状態欄署名は個性化機能にあります。システム字体ページはプレビューと100〜200%の字号を含み、タップで10%ずつ切り替えます。大きな字号でも項目名と値は同じ行に配置します。字体の選択後、読書字体への同期を確認します。「システムのみ」は読書字体を変更せず、「読書字体に同期」は同じパスを保存し、このページで2個目の字体をロードしません。保存失敗は再試行できます。

書架カバーの処理結果をTFカードの隠しフォルダー `.readpico/covers` に保存します。通常・水波紋はグレー縮小画像を再利用し、高速は完成済み白黒ラスタも保存して次回のデコード・拡縮・ディザを省きます。元ファイル・寸法・コントラスト・ディザ位相の変更や破損で再生成します。初回は生成時間が必要です。コラージュロック選択時は書架のアイドル中に一冊ずつ制限付きカバーを `.readpico/locks` に準備し、原比率のカバーと検証済み完成画面を画質を落とさず再利用します。ホームの続きから読むも同じグレーキャッシュと独立した5500バイトの完成済み白黒ファイルを利用し、書棚サイズと干渉しません。切り替え時は以前の形式を解放します。キャッシュは原本と別で削除可能です。TF書き込み失敗でも読書できます。

### 設定・容量・壁紙の修正

設定画面は表示中の行だけ描き、小さいプロフィール画像を再利用します。右矢印は字体とは独立したアイコンで描画します。カードの使用量はマウントされたパーティションの容量と現在の割当数で計算し、FAT32の古い空き容量ヒントはマウント時に一度再計算します。統計が失敗してもカードの読み取りは維持します。読書の時刻は毎分、表示中のステータス部分だけ更新します。

壁紙ロックの完成した16階調ディザ画像を `.readpico/locks/wallpaper.bin` に保存します。初回は生成、以降は検証して直接読み込みます。元画像や向きの変更・破損時は再生成し、書込み失敗でも通常のロックを維持します。追加の全画面バッファは常駐しません。表紙は画面への反映成功まで更新待ちを保持し、イベント中の読込みや表示失敗で消えないようにします。

## 現行ビルド：rc97

RSS を独立した下部タブに移し、設定内の読書入口を削除しました。ホームにはタップできる RSS カードを追加し、ローカル未読数、同期待ち操作数と設定・同期状態を表示します。ホーム表示ではローカル情報だけを読み、接続や本文取得は行いません。

機能と操作は kiikoread rc95 に追従します。表紙・アバターの非同期処理、行単位で中断する先読み、読書開始元への復帰、時刻復元・同期、縦組み修正、元の GC16 全更新と更新後の画素駆動解除を取り込みます。設定リストは慣性なしの一段スクロールです。readll は RSS、ブランド、単一ページサイトと本体内オンライン OTA の無効化を維持します。USB・TF は同じビルドから生成します。


### 読書・低消費電力更新

読書設定は確認済みの半画面2列レイアウトです。自動全更新はタップで5/10/15/30ページ・強制なしを循環し、ページ効果は通常/波紋を切り替えます。ページ領域とキー設定は子画面で選択し、電源キーでのページ送り・全画面没入・挿絵非表示は維持します。手動全更新はキーに割り当てられます。読書波紋は8帯、目標間隔11,090 µsで37相すべてを実行します。ホーム波紋の設定は独立しています。

[公式 a2a63a6](https://github.com/MindReset/read_pico_firmware/commit/a2a63a6a2c606540be72156a6567392d948d65fc)の低消費電力処理を移植しました。スリープ前にタッチ・加速度計・ブザー・IO拡張器を停止し、浅いスリープで浮いたパネル/TFクロック入力をプルダウン、CPU保持領域を準備します。浅いスリープはCW_INT入力を残してキーで復帰し、主制御電源を切る時のみLow出力にします。10分ロック・PIN・読書位置を保持し、PMU処理失敗時は周辺を復元して無限待機/再起動を防ぎます。消費電流は実機測定が必要です。


読書字体の設定にアンチエイリアスのスイッチを追加しました（初期値はオン）。輪郭のみ変更し、組版や追加の字形キャッシュは変更しません。画面下端120pxから上へスワイプすると、タップのページ切替やキー設定に関係なくツールバーを開きます。システム設定の項目名と値は100〜200%でも一行に保ち、長い値は切り詰めます。読書ツールと各設定画面はシステム文字サイズに従い、二列パネルを上へ広げ、元の字形を枠内に収めます。表示とタップの位置を共有し、本文サイズは独立です。どの更新方式でも、既存の一ページ分のカバーキャッシュを読み込んでまとめて表示します。初回は短い処理に分け、準備後に全カバーを表示し、失敗したカバーは仮表示を保ちます。キャッシュ形式の解放とページ切替による中断は維持します。

## 入力方式

九宮格は中国語ピンイン専用で、英語と大文字・小文字の切り替えは全キーボードで使用します。数字は「123」画面から入力します。削除キーを約半秒押し続けると、未確定のピンイン、カーソル前の文字の順に連続削除します。指を離すかキーの外へ動かすと停止し、通常の入力と削除は変更範囲だけ更新します。候補欄が6回変化した後、指を離して約700ミリ秒停止すると、その欄だけを一度グレースケール更新して残像を抑えます。連続入力や削除キーの長押し中は延期し、キーボードの切り替えや画面終了で取り消します。キーを押すと濃くなり少し沈み、離すと元に戻ります。487 個のオフライン単語候補、同音字の継続ページ送り、九宮格の「更多」による読み選択に対応します。内蔵黒体は GB2312 の漢字 6763 字をカバーし、TF カードのフォントは不要です。WiFi パスワードは英語全キーボード・数字・記号を使用します。これらの機能は rc86 リリースに含まれています。

ローカル修正ではオンライン更新前に未表示の表紙キャッシュを解放し、メモリ不足を安全に通知します。画面走査とファームウェアの逐次消去・書き込みを直列化します。進捗は5秒以上経過し5ポイント以上増えた時に、新しい黒い区間と百分率だけを局所更新します。完了済み区間の消去や定期的な画面全消去は行いません。終了・ロック・取消ではタスク終了を待ち、検証失敗時は現在の起動領域を維持します。

## TF カードからのローカル更新

TF カードは現在 FAT16/FAT32 に対応し、exFAT は有効になっていません。容量だけでは互換性を保証できません。ローカル開発版は 40 MHz の初期化失敗後に250ミリ秒待って再試行し、その後20/10 MHzに下げます。高速切替のビジーエラーも再試行します。カード検出の通信エラーを抜去と誤認せず、状態を保持して実際のマウントを試みます。初期化エラーからフォーマットを勧めたり実行したりしません。実際にカードを抜いた後は、ファイル利用を停止して明示的に再マウントするか、本体を再起動してください。

最初に一度だけ、PC から OTA 基本版を完全に書き込み、ブートローダーと二つのファームウェア領域を導入します。既存の設定、読書記録、内部ストレージの位置、TF カードの内容は維持されます。その後はアプリケーション画像を `readll-update.bin` という名前で TF カード直下に置き、「ファイル → 更新 → 更新をインストール」から更新できます。

本体は画像のプロジェクト名、バージョン、サイズとヘッダーを確認し、未使用側の領域だけに書き込みます。完全性の確認後に起動先を切り替え、新しい版が初回起動確認前に異常終了した場合は以前の版へ自動的に戻ります。更新中は電源と TF カードを外さないでください。アプリケーションだけの更新では、最初の OTA 基本版導入やパーティション表の変更はできません。

ビルドには ESP-IDF v6.1 が必要です。ファームウェアには Noto Sans SC Medium のサブセットのみを内蔵し、追加のフォントや書籍は配布しません。

本体の上流コードは Apache-2.0、UI アイコンは Lucide（ISC）、epdiy は LGPL-3.0-or-later、内蔵フォントは SIL OFL 1.1 に従います。適用範囲は [第三者ライセンス一覧](THIRD_PARTY_NOTICES.md)をご覧ください。

### ファイル転送

ファイル管理には WiFi 転送・ホットスポット転送・USB 転送を直接表示します。WiFi は保存済みネットワークに接続し、未設定なら接続設定へ進みます。ホットスポットは本体のアクセスポイントを開始します。USB は PC から TF カードを読み書きできます。

### メイン画面の更新と読書キー

ローカル版のメイン波紋は読書と同じ8帯・44ステップ・11,090µsの目標間隔です。各画素の全37位相を保ち、ソフトウェア目標は624msから約488msになります。実際の遅延には描画と走査も含まれます。メイン画面のグレー波形、固定ナビゲーションと失敗復旧は維持し、画質と残像は実機確認が必要です。

リスト表紙は軽く跳ねて戻ってから本を開きます。移動した表紙範囲のみ更新し、高速は白黒差分、通常・波紋はグレーを維持し、余分な枠は追加しません。

設定の表示から通常・高速・波紋を選択できます。通常と波紋はグレーを保持し、高速は白黒表紙と細かい市松模様を使います。下部ナビゲーションを保持し、選択マークのみ局所更新します。上端から下へスワイプすると WiFi・Bluetooth・全更新・ロックが開きます。読書キーは個別設定と2つの推奨設定に対応し、中央長押しは標準でホームへ戻ります。下端から上へスワイプすると常にツールバーを開くため、キー割り当ては自由で、起動や復元でツールキーを強制しません。戻る操作は読書を開始したホームまたは書棚へ戻します。中央ダブルタップは常に全画面切替です。新しく開く本は全画面となり、ページ送りではツールバーを閉じて全画面へ戻ります。設定は再起動とバックアップ復元で保持されます。

ビルドごとに `tools/upstream.json` の遠隔ブランチを確認し、変更があれば比較リンクを表示します。自動マージは行わず、通信・検査失敗はビルド失敗です。確認・統合後に基準を更新してください。ローカルのオフラインビルドだけは `-DREADLL_SKIP_UPSTREAM_CHECK=ON`（Windows は `-SkipUpstreamCheck`）で明示的に省略できます。公開は `-DREADLL_REQUIRE_CURRENT_UPSTREAM=ON` を必須とし、未確認変更や省略を拒否します。

本版では、ロック前に本・読書位置・全画面状態を保存し、深いスリープからの復元は一度だけ試行します。本の読み込みが電源断や異常再起動で中断した場合、本名とホーム・確認付き削除を表示して自動再試行を止めます。読書票はどの画面からもシステム字体で描画し、浅いスリープ解除後は元の読書字体へ戻します。クイック操作は3モードともグレーと明瞭な枠線を使います。高速モードは白黒表紙のみ、通常・波紋はグレー表紙のみ保持し、変更時に旧形式を解放します。ホームの続読書名はシステム字体を40pxで、読書画面の書名・章題は読書字体を32/48pxで直接生成します。現在の字体を再利用し、内蔵字体の追加やシステム・読書字体の同時読み込みは行いません。字体が利用できない場合は安全な内蔵補完を維持します。これらの変更は rc88 に含まれます。

オンライン書き込みの接続ボタン上で最新版または正式公開時の **rc86 / rc85** を選択できます。公開日時と TF 更新ファイルは選択した版に対応し、すべての版でデータ保持が標準です。

### ローカルテスト：リスト書棚とロック反応

設定の書棚形式に4冊のリストを追加。表紙を120×156pxに統一し、元比率を保って拡大・中央トリミング。著者、進捗、お気に入りを表示し、長い題名は2行までです。形式は再起動・設定復元で保持します。通常・波紋ではグレー、高速では白黒表紙のみを保持します。濃い2pxの枠・区切り線は高速・波紋でも見やすくします。段落字下げに1px刻みの微調整（-20～+20、既定0）を追加し、数値タップでリセット。字下げなしでは適用せず、再起動・設定復元で保持します。PIN画面は一度で表示し、2段階の背景更新を廃止。PIN入力は背景や字体を再描画せず、円内の反応と入力点だけを局所白黒更新します。取消はロックを維持します。拼貼表紙に柔らかい影を加え、白い文字輪郭を細くしました。壁紙・読書票・拼貼画像は16階調の物理グレーとディザリングで256階調の入力輝度を表現します。
